# Default heading for adverse events of special interest

`aesi_heading_msg()` returns the default heading used for adverse events
of special interest (AESI) sections in safety summary tables.

## Usage

``` r
aesi_heading_msg()
```

## Value

A single character string containing the default AESI heading.

## Examples

``` r
aesi_heading_msg()
#> [1] "Total number of patients with at least one"
```
